## How to update?
* In the table, the existing countries are sorted by `Name` ascending. The former countries are sorted by `End date` descending.
* Maintain fixed-width formatting for columns `Name` through `RU`
* The fixed width of the `EN` column is set by the longest English name; when a longer name is introduced, re-pad the whole column (including the header and the separator row).
* Country names in `EN` follow the short names from the `ISO 3166-1` Wikipedia page, but strip qualifiers: remove any part after a comma and any part between brackets (e.g. `Bolivia, Plurinational State of` -> `Bolivia`, `Falkland Islands (Malvinas)` -> `Falkland Islands`). Keep the qualifier when stripping would make two rows share a name (e.g. `Congo, Democratic Republic of the` vs `Congo`, `Virgin Islands (British)` vs `Virgin Islands (U.S.)`), and use `North Korea` / `South Korea` for the Korean rows.
* Former countries (from `ISO 3166-3`) omit the `AR` column, so their rows contain 19 cells instead of 20.
* The `Num` of a former country is taken from `ISO 3166-3` when available; otherwise `000` is used as a placeholder.
* Only sources from the internet can be used, where Wikipedia is preferred over other sources.
* Check `Columns` sections for details per column.
* If possible use RAW data instead HTML.
* It is advised to cache the sources locally (in `.cache` directory) before processing it.
* Markdown tables are advised to split on `|`
* If you get new insights on how to maintain and/or update this file, this section should be updated too to reflect this.
* When code is needed to perform this task, use the `specs/Wikiscraper` project.
