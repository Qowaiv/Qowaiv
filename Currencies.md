## How to update
Download all sources as specified at [Sources](#sources); the first source is leading for codes that should be mentioned.
Only use the downloaded Wikipedia pages and this document, other files should not be used.
If known a single character symbol may be added to the `S` column.
Add and/or update records in the Currencies table. The first label should be `EN`, the should be ordered alphabetically.
Do not include currencies that are not used for day-to-day payments (such as gold, and platinum etc.). This excludes funds codes (BOV, CHE, CHW, CLF, COU, MXV, USN, UYI, BEC, BEL, LUC, LUL, ECV, USS, ZAL), precious metals (XAU, XAG, XPD, XPT), bond market units (XBA, XBB, XBC, XBD), and settlement/account units (XDR, XSU, XUA, XFO, XFU, XRE, XXX). Historic codes without a clear `From`/`Until` date (BUK, GWE, LSM, LTT, MTP, VNC) are not mentioned as well.
Ignore the `(xxxx)` parts in labels.
Normalize dates: a year-only value (`1925`) becomes `1925-01-01` as `Start` and `1925-12-31` as `End`; a month-only value (`1994-12`) becomes `1994-12-31`. Take care of invalid dates, e.g. `2022-06-31` does not exist, the correct `End` for SLL is `2022-06-30`. For the `Euro` transitions, the `End` date is the end of the circulation of the national currency (`2001-12-31`), not the source's `Until` date (`1999-01-01`). Copy the numeric code `Num` verbatim (e.g. SLL is `694`, not `924`).
The [Countries](#countries) table contains a relation between a country and the currency in use.
Mappings are separated by ` ← `. When the start date of the currency in use is added with `(yyyy-MM-dd)`.
The order is descending: so the latest currency first.
